# INDI drivers for smart telescopes

**Author:** [@cgobat](https://github.com/cgobat)

---

This repository contains [pyINDI](https://github.com/MMTObservatory/pyINDI)-based drivers for all-in-one smart telescope platforms such as Seestar, DWARFLAB, and Celestron Origin.
